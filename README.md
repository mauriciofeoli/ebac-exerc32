# Exercicios de Banco de Dados

Neste exercicio foram feitas consultas usando o banco Sakila e o MongoDB.

Na pasta `SQL` estão as consultas de filmes, categorias e atores, junto com as consultas que mostram a quantidade de resultados.

Na pasta `NoSQL` estão as consultas feitas na collection `books`, usando filtros, contagem e expressões regulares.
